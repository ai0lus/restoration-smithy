# 낡은 무기 수리 대장간 (Restoration Smithy)

플레이어가 대장장이가 되어, 의뢰인이 가져온 낡고 녹슨 무기·장신구를 **화살표 퍼즐**로 수리하는 모바일 세로형 퍼즐 게임입니다.
HTML5 Canvas 2D, 빌드 도구 없이 브라우저에서 바로 실행됩니다.

## 실행

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

브라우저에서 http://localhost:8080 을 엽니다. (`index.html`을 파일로 직접 열어도 동작하지만, 그림 로딩은 서버 실행을 권장)

## 게임 흐름

1. **접수대** — 의뢰인(5명)이 낡은 물건을 가져와 수리를 부탁합니다. 물건 그림·손상 설명·보수 표시.
2. **수리 퍼즐** — 판은 물건의 실루엣 모양. 판 뒤에 낡은 물건 그림이 어둡게 깔려 있습니다.
   - 화살표를 누르면 머리 방향으로 몸통 전체가 빠져나갑니다. 머리 앞이 판 끝까지 비어 있어야 빠집니다.
   - 막힌 화살표는 부딪혀 돌아오고 빨갛게 남으며 집중력(♥)이 1 줄어듭니다. 3번 막히면 실패.
   - 화살표가 빠진 경로를 따라 안개가 걷히듯 수리된 그림이 드러납니다.
   - 모두 빼면 같은 자리에서 수리된 물건 전체가 나타나고 보상(보수 + 남은 집중력 × 10 G)을 받습니다.
3. **수리 도감** — 수리한 물건이 기록됩니다.

조작: 탭(뗄 때 확정), 한 손가락 드래그로 판 이동, 두 손가락 핀치(PC는 마우스 휠)로 확대·축소. 하단 버튼은 되돌리기 · 힌트 · 경로(탈출 방향 점선) · 다시.

## 퍼즐 생성 규칙 요약

- 레벨 번호를 시드로 결정적으로 생성하며, **풀이 역순으로 배치**해 항상 풀 수 있습니다.
- 물건 모양(mask)의 모든 점이 화살표 선으로 채워집니다.
- 짧은 화살표가 일렬로 이어지거나 뭉치지 않도록 병합·흡수하고, 네 방향이 고르게 섞입니다.
- 회차가 오를수록 판이 2→3→4배로 커지고(최대 40×52), 처음부터 풀리는 화살표 비율이 줄어 난이도가 올라갑니다.

자세한 구현 스펙은 [CLAUDE.md](CLAUDE.md)를 참고하세요.

## 폴더 구조

| 경로 | 내용 |
|---|---|
| `index.html` | 진입점 (540×960 세로 캔버스) |
| `src/engine.js` | 게임 루프, HiDPI 렌더링, 탭·드래그·핀치 입력 |
| `src/puzzle.js` | 화살표 퍼즐 규칙과 레벨 생성기 |
| `src/items.js` | 의뢰인 5명, 의뢰 물건 10종(이름·설명·보수·모양) |
| `src/game.js` | 접수대 · 수리 퍼즐 · 도감 화면, 저장 |
| `src/assets.js` | 그림 로더 |
| `src/sfx.js`, `src/fx.js` | 효과음(Web Audio 합성), 파티클 |
| `assets/images/` | 게임용 그림 (의뢰인, 물건 수리 전/후, 아이콘) |
| `tools/resize_art.ps1` | 원본 그림을 모바일용으로 축소 |
| `CODEX_ASSETS.md`, `AGENTS.md` | Codex 그림 제작 요청서·규칙 |
| `_archive/` | 이전 컨셉 코드 보관 (로드 안 함) |
